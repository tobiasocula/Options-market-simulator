
## Running the simulator (cross excitation)

To run the simulator, simply run

```
streamlit run streamlit_cross_excitation/Overview.py
```

in the terminal. To run the cross-excitation application again, run the ```run.py``` script in the ```cross_runs_scripts``` directory and change the parameter set if desired.

## Running the simulator (self excitation)

One could similarly run this version of the application, but beware that I quickly moved on to the more sophisticated implementation being the cross excitation version, and the implementation hasn't been checked ever since, and might not work 100% correctly.

## Visualizing results using Streamlit

In the ```streamlit_cross_excitation``` directory, run the ```Overview.py``` script to visualize the results from the simulation.
